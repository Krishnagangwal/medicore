**Old prediction records cleanup:** No TTL indexes in PostgreSQL. The deterioration.job.js cron runs a cleanup query at midnight daily:
```js
// Delete predictions older than 90 days
await prisma.prediction.deleteMany({
  where: { createdAt: { lt: new Date(Date.now() - 90 * 24 * 60 * 60 * 1000) } }
})
// Delete notifications older than 30 days
await prisma.notification.deleteMany({
  where: { createdAt: { lt: new Date(Date.now() - 30 * 24 * 60 * 60 * 1000) } }
})
```

## JWT structure

```json
{
  "sub": "user-uuid",
  "email": "user@medicore.local",
  "role": "DOCTOR",
  "fullName": "Dr. Sharma",
  "patientId": null,
  "iat": 1720000000,
  "exp": 1720086400,
  "iss": "medicore-api"
}
```

`patientId` is only populated when `role === "PATIENT"`. It links the token directly to the `patients` table row — no extra lookup needed for patient-scoped requests.

Algorithm: HS256. The **same** `JWT_SECRET` environment variable is set in both `backend/.env` and `ai-gateway/.env`. FastAPI uses `python-jose` to verify tokens without calling the Node.js backend.

Access token lifetime: 24h. Refresh token: 7 days, stored in httpOnly cookie only.

## AI Gateway — unified JSON contract

Full schema: `docs/gateway-schema.md`

Every model block in the response follows this shape:
```json
{
  "status": "success | error | timeout | skipped",
  "latency_ms": 234,
  "result": { /* model-specific, see gateway-schema.md */ },
  "error_message": null
}
```

SHAP values shape (same across all models):
```json
[
  {
    "feature": "heart_rate",
    "display_name": "Heart rate",
    "value": 118,
    "impact": 0.41,
    "direction": "increases_risk"
  }
]
```

Gateway request shape:
```json
{
  "patient_id": "uuid",
  "encounter_id": "uuid",
  "models": ["triage", "deterioration", "lab_parser", "drug_interaction", "differential_dx", "readmission"],
  "context": {
    "symptom_text": "string",
    "medications": ["Drug A", "Drug B"],
    "lab_report_id": "uuid or null",
    "vitals_last_n": 3
  }
}
```

Timeout per model: 10 seconds. Always return partial results — never fail the whole response because one model timed out.

**Model 6 (Diff Dx):** DDXPlus dataset — download from `github.com/mila-iqia/ddxplus`. If not yet downloaded, use symptom-disease mapping from MIMIC-III discharge notes (available in MIMIC-IV Demo).

## Coding conventions

**Python (Krishna):**
- PEP8 enforced. Run `black` before committing.
- Type hints on every function signature.
- Docstring on every public function.
- All prediction functions return a dict matching the gateway-schema.md shape — no deviations.
- Never raise unhandled exceptions in FastAPI endpoints. Always return `{"status": "error", "error_message": str(e)}`.

**JavaScript (Khushi):**
- `async/await` everywhere. No callbacks, no `.then()` chains.
- `try/catch` on every async function.
- Every API error returns `{ error: string, code: string, statusCode: number }`.
- All dates stored and transmitted as ISO 8601 strings.
- React: functional components only. No class components.
- Prisma client: always instantiate once in `backend/src/lib/prisma.js` and import from there. Never create multiple Prisma instances.

**Git:**
- Feature branches only. Never commit directly to `main`.
- Branch naming: `krishna/model-1-triage`, `khushi/patient-portal`.
- Commit message: imperative present tense — "Add SHAP integration to Model 2", not "Added" or "Adding".
- Never commit `.env` files. Only `.env.example` is committed.

## Prisma usage patterns (Khushi reference)

```js
// backend/src/lib/prisma.js — singleton, import this everywhere
import { PrismaClient } from '@prisma/client'
const prisma = new PrismaClient()
export default prisma

// Example route: get patient with latest encounter
const patient = await prisma.patient.findUnique({
  where: { id: patientId },
  include: {
    encounters: {
      where: { status: 'ACTIVE' },
      orderBy: { admittedAt: 'desc' },
      take: 1,
      include: { vitals: { orderBy: { recordedAt: 'desc' }, take: 5 } }
    }
  }
})

// Example: get last N vitals for deterioration job
const vitals = await prisma.vital.findMany({
  where: { encounterId },
  orderBy: { recordedAt: 'desc' },
  take: 3,
  select: { heartRate: true, systolicBp: true, diastolicBp: true, temperature: true, respiratoryRate: true, spo2: true, recordedAt: true }
})
```
